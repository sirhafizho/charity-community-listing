# Suggested Commands
- `npm run dev` — start the Next.js dev server
- `npm run lint` — run ESLint
- `npm run build` — production build with type-checking
- `npx prisma generate` — regenerate Prisma client
- `npx prisma db push` — sync schema to local SQLite database
- `npm run prisma:migrate` — run Prisma migrations in dev
- `npm run prisma:seed` — seed admin user, categories, and sample listings
- `npm run prisma:studio` — open Prisma Studio
- `git --no-pager status --short` — inspect working tree
